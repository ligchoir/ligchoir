# Projects shortlist for the new site (GitHub issue #50)

**Status 2026-11-08:** Rob chose one Project per story (no grouped pages).
`scripts/devops/projects_batch_2026_11.php` created the twelve flagship
items below as 23 projects (groups 8 to 12 split into their separate
stories) plus 23 Collaborator nodes, with the existing events linked as
outcomes. Section 2 and 3 items are not created yet.

Compiled 2026-11-08 from three sources: 156 choir newsletters 2018–2026, the
members' WhatsApp notice board 2020–2026, and the 109 event nodes already on
the site. The detailed research (with newsletter dates, chat dates, links and
names) is in the private notes folder, not this repo:
`site-dev/ligc-private/2026-11/projects-research/`.

The site has one Project so far: London International Voices (node 143).
Below are the candidates to add, grouped by how we might model them. Event
nodes that already exist are named so they can be linked as `field_outcomes`.

Naming rules agreed in the research: first names of members only; private
and corporate clients left off or anonymised; the Zemel Choir asked (Oct
2026) not to be promoted online, so Faithful Voices should be described
without pushing their name.

## 5. What this means for the data model (issue #51)

Nearly every flagship project has several partners of different kinds: a
partner choir, a festival or promoter, a venue, an artist, a charity. A
compound "collaboration" field on the Project (organisation, kind of
collaboration, note) would carry that cleanly and keep each project's
partners inside the project node. Outcomes can already point at the event
nodes listed above.
