Social icons from Bootstrap Icons (https://icons.getbootstrap.com, MIT, see
LICENSE-bootstrap-icons.txt). Drawn by css/styles/_social.css through a CSS
mask from the Font Awesome class names editors already use in content
(`fab fa-instagram`, `fa-facebook-f`, `fa-x-twitter`, `fa-youtube`,
`fa-spotify`, `fa-linkedin`). To add one: drop the SVG here and add a
`.fa-<name> { --ligc-icon: url(../../images/icons/<name>.svg); }` rule.
